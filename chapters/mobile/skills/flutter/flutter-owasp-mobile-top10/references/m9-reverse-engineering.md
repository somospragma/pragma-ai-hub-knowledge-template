## Check M9-A: Revealing metadata and comments

**ID:** `M9-A-REVEALING-METADATA`
**Objective:** Detect comments, TODOs, and metadata that reveal sensitive information.
**Scope:** `lib/**.dart`, `pubspec.yaml`, `README.md`

**Method:** Lexical search
**Patterns:**

```dart
// PATTERN 1: TODOs with sensitive information
// TODO: Change hardcoded password: admin123          // ❌ DANGER
// FIXME: Temporary API key AIzaSyC1234567890         // ❌ DANGER
// HACK: Auth bypass for testing                      // ⚠️ Revealing

// PATTERN 2: Comments with credentials
// Test credentials:
// user: admin@example.com
// pass: Test123!                                     // ❌ DANGER

// PATTERN 3: Comments about vulnerabilities
// This function has a security bug but it works      // ⚠️ Revealing

// PATTERN 4: Internal/staging URLs
// const API_URL = 'https://internal-staging.company.com';  // ⚠️ Exposes infrastructure
```

**Lexical search:**
```bash
# TODOs/FIXMEs with sensitive data
grep -rE "TODO.*password|TODO.*secret|TODO.*admin|TODO.*key" lib/

# Comments with credentials
grep -rE "//.*password.*:|//.*user.*:|//.*credential" lib/

# Comments about bugs/vulnerabilities
grep -rE "//.*(bug|vulnerability|exploit|bypass|hack)" lib/

# Internal URLs
grep -rE "(staging|internal|dev|test)\.(company|corp)" lib/
```

**Criteria:**
- ❌ **Fail:** TODOs/comments with passwords, keys, or credentials
- ⚠️ **Warning:** Comments that reveal security logic
- ⚠️ **Warning:** Revealing metadata (internal names, URLs)
- ✅ **Pass:** Clean comments, generic metadata

**Severity:** `LOW`
**Automation:** 🟢 High (85%)

**Remediation:**

```dart
// ❌ BAD
// TODO: Change hardcoded password: admin123
// FIXME: This API key is temporary: AIzaSyC1234567890

// ✅ GOOD
// TODO: Migrate to OAuth2 authentication
// FIXME: Fetch API key from configuration server

// ❌ BAD — Revealing logic
// This function bypasses auth if the user has @company.com email
if (email.endsWith('@company.com')) {
  return true;  // Backdoor for admins
}

// ✅ GOOD — No sensitive logic revealed
if (_isAdminUser(email)) {
  return _validateAdminAccess();
}
```

```yaml
# ❌ BAD — pubspec.yaml
name: internal_banking_admin_backdoor
description: Admin tool with special access for internal auditing and backdoor access
homepage: https://internal-dev.banking-corp.com

# ✅ GOOD — pubspec.yaml
name: banking_admin_app
description: Administrative dashboard for banking operations
homepage: https://www.banking-corp.com
```

## Check M9-B: Unobfuscated Dart code in production

**ID:** `M9-B-UNOBFUSCATED-DART`
**Objective:** Verify that Dart code is obfuscated in release builds.
**Scope:** Build scripts, CI/CD workflows

**Method:** Lexical search in automation files
**Detection:**
```bash
# Find build commands without --obfuscate
grep -r "flutter build" .github/workflows/ | grep -v "\--obfuscate"
grep -r "flutter build" .gitlab-ci.yml | grep -v "\--obfuscate"
grep -r "flutter build" Makefile | grep -v "\--obfuscate"
```

**Criteria:**
- ❌ **Fail:** `flutter build apk/ios` without `--obfuscate`
- ⚠️ **Warning:** Obfuscation enabled but symbols not saved
- ✅ **Pass:** `--obfuscate` + `--split-debug-info` in all release builds

**Severity:** `MEDIUM`
**Automation:** 🟢 High (95%)

**Remediation:**

```yaml
# ✅ .github/workflows/release.yml
- name: Build App Bundle with obfuscation
  run: |
    flutter build appbundle --release \
      --obfuscate \
      --split-debug-info=build/app/outputs/symbols

- name: Upload symbols to Firebase Crashlytics
  run: |
    firebase crashlytics:symbols:upload \
      --app=1:1234567890:android:abc123 \
      build/app/outputs/symbols
```

```makefile
# ✅ Makefile
build-release-android:
	flutter build apk --release \
		--obfuscate \
		--split-debug-info=build/symbols/android \
		--target-platform android-arm,android-arm64

build-release-ios:
	flutter build ios --release \
		--obfuscate \
		--split-debug-info=build/symbols/ios
```

## Additional Protection Strategies

### 1. Sensitive string obfuscation

```dart
// ❌ Plaintext strings are easy to extract
const apiEndpoint = 'https://api.example.com/v1';

// ✅ Basic XOR obfuscation for sensitive strings
class ObfuscatedStrings {
  static String _decode(List<int> encoded, int key) =>
      String.fromCharCodes(encoded.map((b) => b ^ key));

  // Generated by an obfuscation script at build time
  static String get apiEndpoint => _decode([
    0x68, 0x74, 0x74, 0x70, 0x73, 0x3a, 0x2f, 0x2f,
    0x61, 0x70, 0x69, 0x2e, 0x65, 0x78, 0x61, 0x6d,
  ], 0x00);
}
```

### 2. Native code for critical logic

