## 1. File Structure

```
lib/
├── core/
│   └── error/
│       ├── failures.dart              ← Failure with FailureMessageKey (no Strings)
│       └── failure_message_key.dart   ← i18n key enum
│
└── l10n/
    ├── app_en.arb                     ← English (base language)
    ├── app_es.arb                     ← Spanish
    └── l10n.yaml                      ← Generator configuration

# Automatically generated by flutter gen-l10n:
└── .dart_tool/flutter_gen/gen_l10n/
    └── app_localizations.dart
```

---

## 2. l10n.yaml Configuration

```yaml
# l10n.yaml — at the project root

arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
synthetic-package: false          # generates in lib/, not in .dart_tool
output-dir: lib/core/l10n/generated
```

## 5. i18n Checklist

- [ ] Every new ARB entry has its `@key` with a `description`
- [ ] `app_en.arb` is the **template** file — add in English first, then in Spanish
- [ ] Run `flutter gen-l10n` after every change to the ARB files
- [ ] The Retry button uses `l.retryButton` — not a string literal
- [ ] All keys are present in **both** ARB files before building
